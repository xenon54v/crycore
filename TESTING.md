# CryptoCore Testing

## Sprint 3 — CSPRNG testing

В Sprint 3 был добавлен отдельный модуль CSPRNG для генерации криптографически стойких случайных данных.

Для генерации используется функция:

```python
generate_random_bytes(num_bytes: int) -> bytes
```

Внутри используется системный источник случайности `os.urandom()`.

## Автоматические тесты

Для запуска всех автоматических тестов проекта:

```powershell
pytest -v
```

В рамках Sprint 3 дополнительно проверяется:

- генерация случайных байтов требуемой длины;
- обработка некорректного размера;
- генерация 1000 уникальных 16-байтовых ключей;
- базовое распределение битов;
- автоматическая генерация AES-128 ключа при отсутствии `--key`;
- успешное шифрование и последующее расшифрование с автоматически созданным ключом;
- обязательность `--key` при расшифровании;
- предупреждение о слабом пользовательском ключе;
- сохранение interoperability-тестов с OpenSSL.

## Подготовка данных для NIST STS

Для статистической проверки CSPRNG используется скрипт:

```text
scripts/generate_nist_data.py
```

Он создаёт бинарный файл:

```text
nist_test_data.bin
```

Размер файла:

```text
10 000 000 байт
```

Это соответствует:

```text
80 000 000 бит
```

Данные полностью генерируются через функцию `generate_random_bytes()`.

Запуск генерации:

```powershell
python scripts/generate_nist_data.py
```

## NIST Statistical Test Suite

Для проверки был использован NIST Statistical Test Suite версии 2.1.2.

Тестирование выполнялось в WSL2 / Ubuntu.

Программа запускалась командой:

```bash
./assess 1000000
```

Длина одной анализируемой последовательности:

```text
1 000 000 бит
```

Количество последовательностей:

```text
80
```

Формат входных данных:

```text
Binary
```

Были запущены все 15 статистических тестов NIST STS.

Использовались стандартные параметры:

```text
Block Frequency Test: M = 128
NonOverlapping Template Test: m = 9
Overlapping Template Test: m = 9
Approximate Entropy Test: m = 10
Serial Test: m = 16
Linear Complexity Test: M = 500
```

## Результаты NIST STS

Итоговый отчёт сохранён в:

```text
docs/nist/finalAnalysisReport.txt
```

Для выборки из 80 последовательностей минимальная допустимая доля успешных последовательностей составила:

```text
76 / 80
```

Для Random Excursions и Random Excursions Variant анализировалось 47 подходящих последовательностей, минимальная допустимая граница составила:

```text
44 / 47
```

Примеры результатов:

```text
Frequency               78/80
BlockFrequency          80/80
CumulativeSums          78/80
Runs                    80/80
LongestRun              80/80
Rank                    77/80
FFT                     79/80
Serial                  80/80
LinearComplexity        79/80
```

Команда:

```bash
grep '\*' experiments/AlgorithmTesting/finalAnalysisReport.txt
```

не вывела ни одной строки.

Это означает, что итоговый отчёт NIST STS не содержит тестов, помеченных как не прошедшие по критериям набора.

Отдельные P-value ниже `0.01` встречались в отдельных строках Random Excursions Variant, однако NIST STS не отметил их как общий провал теста, а итоговые пропорции успешных последовательностей оставались выше допустимого минимума.

## Вывод

CSPRNG на основе `os.urandom()` успешно прошёл автоматические тесты проекта, тест на уникальность 1000 ключей, базовую проверку распределения битов и полный набор NIST STS.

По итоговому отчёту статистических тестов критических отклонений не обнаружено.
